🚀 Auto-Translate

Translate pages as soon as they load, without clicking anything.

Automatically translate pages
A page is translated on load when it declares a language other than your target language. Pages that don't declare one are left alone. Every translation runs on your own machine, so this costs real time and CPU on each page you open. Enabling this will ask for permission to run on all websites.

Languages you already read. Your target language is always excluded.

Subdomains are covered too — example.com also blocks news.example.com. The banner shown while a page auto-translates can add sites here for you.

⚡ Performance

Tune batch size and concurrency for your hardware.

Higher values = fewer API calls, but may hit model limits.

Lower values = faster visual feedback as translations appear.

Lower = more consistent translations. Higher = more creative.

LMStudio 0.4.0+ supports up to 4 parallel requests for faster translation.

📤 Output Settings

Control how translations are displayed and how models respond.

Structured JSON output
Requests JSON format from the model. Disable if the model struggles with JSON.
Plain-text fallback
If a segment keeps coming back malformed, retranslate it as plain text. Slower, but avoids leaving text untranslated.
Translation glow effect
Visual indicator when text has been translated on the page.
Debug logging
Verbose logs for troubleshooting. View in about:debugging → Inspect → Console.

💾 Translation Cache

Reuse stored translations for identical text so repeated content isn't re-translated. Stored locally, never uploaded.

⚠️ This browser doesn't support keeping the cache across sessions.

📖 Glossary

Force consistent translations for specific terms. Whole-segment matches bypass the model entirely; partial matches are injected as prompt hints so the model stays consistent. Only matching terms are sent per request — a large dictionary is fine.

Enable glossary
Source term Translation (leave empty to keep as-is)

● Unsaved changes

TSV format for import: one line per term, source<TAB>translation. Add a #target: ja line to limit the glossary to a specific target language.
